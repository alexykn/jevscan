# New-rule finalist evidence

This directory contains concise public aggregates from the finalist review. The
final production decision and public-safe inventory are recorded in
[`../NEW_RULE_DISCOVERY.md`](../NEW_RULE_DISCOVERY.md).

## Retained aggregates

- [`usefulness-results.md`](usefulness-results.md) and
  [`usefulness-results.json`](usefulness-results.json) record reviewed cases,
  labels, utility, dispositions, and privacy controls.
- [`cost-ledger.json`](cost-ledger.json) records cumulative request and cost
  accounting without source or run identity.

The five promoted candidates are installed as exactly five non-blocking
built-ins, JEV12 through JEV16. Private and local-only review materials remain
outside this public assembly.
